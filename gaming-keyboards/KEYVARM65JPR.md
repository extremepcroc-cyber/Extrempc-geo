- **The "Ariel" colourway is a designed case, not a neutral one** — at this tier the case is part of the product. Ariel is a considered finish rather than a colour-block, which suits a premium desk where the keyboard is meant to read as a designed object.

- **Magnetic switches with rapid trigger — the competitive feature** — a key re-actuates after as little as 0.1mm of movement in the opposite direction rather than requiring a full return past a fixed reset point. In CS2 and Valorant that's faster counter-strafing and more consistent bunny-hopping.

- **No contact wear** — Hall Effect sensing reads the magnet's position rather than closing a metal contact, so there's no contact-oxidation ceiling of the kind mechanical switches carry (industry rating: 50–100 million keystrokes). On a premium board intended to last years, the wear mechanism simply isn't there.

- **Per-key RGB plus hot-swap sockets** — the lighting is fully per-key, and the sockets accept the standard switch families, so the Jade Pro isn't a permanent commitment on a board at this price.

## FAQ

- **Q: What's the practical difference between the Jade Pro and a value-tier magnetic switch?**
  A: Tuning and family. The Jade Pro is a defined Gateron magnetic line at its Pro revision with its own spring weight and sound character; the value-tier boards adopt vendor lines (Apollo, Kailh, TTC, Clear Mag) as-is. The honest answer is that the difference is best felt rather than read — the Build Team can set both up at Onehunga so you can compare.

- **Q: Does it support rapid trigger?**
  A: The board carries magnetic switches, which enable rapid trigger and adjustable actuation. If rapid trigger is a hard requirement, confirm the current firmware feature set with the Build Team before purchase.

- **Q: Why is it wired only at this price?**
  A: Wired removes the wireless variable entirely — no battery, no dongle, no latency question. If you need wireless in this tier, the VA100 Goddess Luo is the wireless Varmilo option.

- **Q: Why no arrow keys or F-row?**

- **Q: Can I use it with a Mac?**
