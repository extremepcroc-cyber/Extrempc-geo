## FAQ

- **Q: Is it wireless, and is it Bluetooth?**
  A: The VA100 is a wireless mechanical keyboard plus USB-C wired. Note the BC listing identifies it as wireless; if Bluetooth multi-device pairing specifically is a requirement for you, ask the Build Team to confirm the current connectivity modes for this SKU before purchase.

- **Q: What's the Kailh Prestige Voice switch like?**
  A: It's a mechanical switch from Kailh's Prestige line tuned for an audible character — you hear the keystroke. If you'd rather a quieter board, the VA80 Hygge is available with the Prestige Silent switch (KEYVARVA80HPS), though that's the 84-key layout without the numpad.

- **Q: Does it have a numpad and an F-row?**
  A: Yes — 105 keys is a full-size layout with the number pad, function row, arrow cluster, and function block. That's the difference versus the 65% and 75% premium Varmilo models.

- **Q: Are the switches hot-swappable?**
  A: Yes. The sockets accept the standard switch families, so the Prestige Voice switches can be swapped for a different switch type later without soldering — which also lets you change the sound profile.

- **Q: Can I use it with a Mac?**
