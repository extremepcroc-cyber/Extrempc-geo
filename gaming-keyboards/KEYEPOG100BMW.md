## FAQ

- **Q: What's the difference between QMK and VIA, and do I need to know code?**
  A: VIA is a browser-based configurator with a visual keymap editor — no code required for remapping, layers, or macros. QMK is the underlying open-source firmware, which you'd edit at the code level only if you want custom behaviour VIA can't express. Start with VIA; most users never need QMK.

- **Q: Is the Feker Marble White switch made by Epomaker?**
  A: No — it's a Feker switch line rather than an Epomaker in-house switch. Epomaker develops its own lines (Creamy Jade, Wisteria, Flamingo, Zebra) for other models; the Galaxy 100 carries Feker's Marble White. Because the board is hot-swap, you're not locked to it either way.

- **Q: Is it 2.4GHz or Bluetooth, or both?**
  A: The Galaxy 100 runs 2.4GHz wireless plus USB-C wired. If you need Bluetooth pairing for a tablet or phone, Epomaker's tri-mode models are the alternative.

- **Q: Are the switches hot-swappable?**
  A: Yes. Standard sockets accept the main switch families, so the Feker Marble White can be swapped for another switch type without soldering.

- **Q: How much stock is there?**
  A: Low stock at the moment — a single unit at Onehunga. Confirm availability with the store before planning around it.

- **Q: Does VIA work on macOS?**
  A: Yes — VIA runs in a Chromium-based browser, so it's cross-platform including macOS. That's a practical advantage over brands whose remapping software is Windows-only.
