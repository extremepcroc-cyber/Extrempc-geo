## FAQ

- **Q: What does the 3.98" display actually show?**
  A: Battery status, the active connection mode, and customisable content (AULA's L99 spec). The customisable content means you can set it to show static graphics or text beyond the functional readouts. If you want to see the exact content options on the current firmware, ask the Build Team — they can show you on a demo unit at Onehunga.

- **Q: Is the display a gimmick, or does it earn its place?**
  A: For a single-device wired setup it's a nice-to-have. For a tri-mode setup that jumps between a laptop, a phone, and a desktop, it's a genuine status hub — you see at a glance which device you're on and how much charge is left, instead of memorising the mode key. The value comes from the multi-device workflow.

- **Q: Is it really tri-mode, or just 2.4GHz?**
  A: Tri-mode. 2.4GHz via USB-C dongle for low-latency gaming, Bluetooth for a laptop or phone, and USB-C wired. Switch modes on the board itself; the display confirms the active mode.

- **Q: Are the switches hot-swappable?**
  A: Yes. 5-pin/3-pin sockets accept LEOBOG, Kailh, Gateron, and TTC. Swap the Caramel Latte for a different linear or tactile without soldering.

- **Q: How much stock is there?**
  A: This is a low-stock unit at the moment — a few units at Onehunga. If you want it, check with the store before assuming it'll still be there next week.

- **Q: Can I use it with a Mac?**
  A: Bluetooth and USB-C wired both work on macOS out of the box. The 2.4GHz dongle also works on Mac. Key remapping software is Windows-first; on Mac you'll use the system defaults.
