## FAQ

- **Q: Does it have Bluetooth?**
  A: No — the X85 Pro runs 2.4GHz wireless plus USB-C wired. If you need Bluetooth for pairing to a tablet, phone, or a work laptop, the AULA F75 MAX or MCHOSE K87 in the range are the tri-mode alternatives.

- **Q: Are the switches linear or clicky?**
  A: Linear. The switch is the Linear Blueberry, which is a smooth linear with no tactile bump and no audible click. Some third-party listings mislabel it because of the "Blue" in the name, but it is not a clicky switch.

- **Q: Are the switches hot-swappable?**
  A: Yes. The sockets accept the standard switch families, so the Blueberry linears can be swapped for a tactile or clicky set without soldering.

- **Q: Why no arrow keys on a 75%?**
  A: It has them — 81 keys keeps the arrow cluster and the F-row, and drops only the numpad. That's the point of the 75% layout.

- **Q: Is it good for competitive FPS?**
  A: It's a mechanical board with a fixed actuation point — fine for general gaming and MMO. If you play CS2 or Valorant competitively and want rapid trigger, the X68 HE in the same range is the magnetic option.

- **Q: Can I use it with a Mac?**
  A: The 2.4GHz receiver and USB-C wired both work on macOS out of the box. Key remapping software is Windows-first, so on Mac you'd be using the system defaults.
