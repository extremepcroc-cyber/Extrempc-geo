## FAQ

- **Q: Single stick vs 2× 8GB kit — which?**
  A: Single 16GB stick is the modern baseline for Windows 11 + browser + a light game. If you're upgrading an 8GB system to 16GB, this single stick works. If you're building new, a 2× 16GB kit (32GB total) gives you the dual-channel bandwidth boost that matters for gaming (10–15%).

- **Q: Will it work with my AM4 / LGA1700 DDR4 motherboard?**
  A: Yes — AM4 (Ryzen 1000–5000), LGA1200 (10th/11th Gen Core), and LGA1700 DDR4 (Z690/B660/B760 DDR4) all support DDR4-3200. For DDR5 motherboards (AM5, LGA1851, LGA1700 DDR5), you need DDR5 — physically incompatible.

- **Q: XMP safe?**
  A: Yes — XMP 2.0 is a factory-tested overclock at 1.35V, within JEDEC safe range. No long-term reliability impact.

- **Q: Can I add another 16GB stick later for 32GB?**
  A: Yes — buy a second matching 16GB stick (ideally the same SKU and production run) for a 32GB dual-channel build. Mixing different kits is riskier for training failures.

- **Q: Lifetime warranty — how does it work?**
