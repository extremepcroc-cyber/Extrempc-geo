## Q: 装机收多少钱？

**PC 组装 + 装系统（打包价）：**
- 普通定制机组装 + OS 安装：$199
- 工作站级组装 + OS 安装：$299

**如果客人只带零件来（不在本店购买）**
- 人工费 $250 起步，根据难易程度浮动

**分项硬件安装人工费**（单独加装某个部件时按此收费，非整机组装）
- CPU / 散热器（风冷）/ RAM / SSD or HDD / 显卡：各 $80
- 主板安装 / 电源安装：各 $120
- 水冷安装：$350–450（按复杂程度浮动，非 $120——不要用分项安装的价格套用水冷）
- 理线：$80

**系统安装（OS Install，单独安装，不含组装）**
- Windows 不备份：$150 / macOS 不备份：$200
- Windows 含备份：$250 / macOS 含备份：$320
- 含额外备份（Outlook、MYOB、邮件）：$380（旧版数据，新表未提及此档，暂按旧版处理）
- ⚠️ Mac 只提供 macOS 安装，**不提供在 Mac 上装 Windows**（Apple Silicon Mac 已不支持 Boot Camp）

**数据迁移（故障 PC → 新 PC）**
- 普通文件迁移：$180
- 含额外文件（Outlook、MYOB）：$280

**清灰服务：$120**（固定价，台式机/笔记本通用）

**杀毒服务：** 不备份 $300 / 含备份 $400

**Windows 或驱动更新：$80**

> 完整价格表见 `product-knowledge/service-pricing.md`

## Q: 质保怎么处理？RMA 流程是怎样的？

**保修流程**
- 客人寄回给 ExtremePC
- 我们做好保修后寄回给客人

**⚠️ 保修年限（真实政策，2026-09-07 / 09-14 两次确认）：**
- **笔记本：绝大部分带 1 年厂商保修（1-year manufacturer warranty）** — 厂商保修，非店保
- **台式整机：默认 2 年 Return to Base 保修**（BC 产品页 Subtitle 字段明确标注 "Two Years Warranty"）
  - 可付费升级：**$149 升级到 3 年** Return to Base 保修（产品页 "Upgrade Warranty Time" 选项）
- **桌面组件/外设：保修年限因品牌而异**（如 Corsair PSU 7 年、LiberNovo 框架 5 年/电子 2 年）— 以厂商保修为准，无统一年限
- ⚠️ **不要编造年限** — 不确定时回答"带厂商保修/整机 2 年保修，具体以产品页为准"，或让客人提供型号由店员确认。EVA 曾编造过"1 年店保"（笔记本）/"3-5 年店保"（桌面组件），均为不实信息

**数据来源**：整机保修年限可从 BC 产品页 `Subtitle` 自定义字段读取；组件保修查厂商规格。

**RMA 情况**
- 五花八门，因产品和故障情况而异
- **建议客人直接发邮件到 info@extremepc.co.nz**
- 由真人员工处理具体 RMA 事宜

## Q: 整机 listing 没标品牌，你们会用哪些品牌？

**政策（2026-09-22 店主确认）：优先使用 ExtremePC 是代理商的品牌。**

| 部件 | 优先品牌 | 说明 |
|---|---|---|
| **内存 RAM** | **Whalekom / Team / ADATA** | ⚠️ 目前内存严重缺货，实际用哪个取决于**当时有货的品牌** |
| **主板 MB** | **ASRock** | ExtremePC 是 ASRock 代理商，优先用 ASRock |
| **电源 PSU** | **Thermalright** | ExtremePC 是 Thermalright 代理商，优先用 Thermalright |
| **显卡 GPU** | **ASRock / Colorful** | ExtremePC 是这两家的代理商，优先用这两个品牌 |
| 机箱 Case | 按 listing 标注（常见 Zalman / Jonsbo 等） | — |

**⚠️ 关键**：这是"优先/预期"品牌，**不是绝对承诺** —— 最终用料取决于装机时的库存。listing 只标瓦数/规格而非品牌，就是因为 build sheet 会随库存变化，但**一定出自上述品牌之一**。

**给客人的英文回答模板（直接可用）：**

> When a build's listing doesn't name the brand, we prioritise the brands we're an authorised NZ distributor for:
> - **Motherboard**: ASRock (we're an ASRock distributor)
> - **Power supply**: Thermalright (we're a Thermalright distributor)
> - **Graphics card**: ASRock or Colorful (we're distributors for both)
> - **RAM**: Whalekom, Team, or ADATA — memory is in very short supply right now, so the exact brand depends on what's in stock at build time.
>
> That's why the listing shows spec (wattage / capacity) rather than brand — but it will always be one of these. If you need the exact brand in the current batch, ring the store on 09 849 4999 and they can check the build sheet.

**要点**：① 给出品牌范围（有参考价值，不是空话）② 说明是"优先"而非"保证" ③ 需要确切品牌时引导电话确认当前批次。
